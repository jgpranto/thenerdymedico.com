# the nerdy medico

Official website for **the nerdy medico** — a personal platform for Nahid Hasan, MD,
covering medicine, education, life, travel, and beyond

🌐 https://thenerdymedico.com

## About

the nerdy medico is a personal website that brings together Nahid's medical
journey, educational work, social platforms, and selected moments from life
outside medicine.

## Built With

- HTML5
- CSS3
- JavaScript
- Supabase
- GitHub Pages

## Features

- Cinematic interactive homepage
- Interactive photo gallery
- Private admin panel
- Bio and social-link management
- Gallery upload, captions, deletion, and reordering
- Supabase authentication and storage

## Deployment

The website is hosted using GitHub Pages with the custom domain
`thenerdymedico.com`.
